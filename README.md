# JD Times Frontend (Next.js)

## 디자인 컨셉

이 앱의 핵심 가치는 "여러 언론사가 같은 소식을 보도했는지 한눈에 확인"하는 것입니다.
그래서 통신사(wire service) 느낌을 시그니처로 잡았습니다:

- **헤드라인**: 세리프체(Source Serif 4) — 신문 기사 제목의 무게감
- **타임스탬프/카운트**: 모노스페이스(IBM Plex Mono) — 텔레타이프 느낌
- **시그니처 요소**: 클러스터 카드 상단의 점선 원형 "N건 확인" 스탬프 — 몇 개 언론사가 같은 뉴스를 냈는지 보여주는 이 앱만의 표식
- **색**: 페이퍼 톤 배경 + 인디고 블루(액션) + 앰버(미확인 강조) + 브릭레드(북마크)

## 1. 설치 및 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 2. 백엔드 연결 설정

`.env.local` 파일에 Cloudflare Worker 백엔드 주소가 이미 설정되어 있습니다:

```
NEXT_PUBLIC_API_BASE_URL=https://jd-times-backend.jaedong-jung.workers.dev
```

다른 주소를 쓰신다면 이 값을 바꿔주세요.

## 3. 프로덕션 빌드

```bash
npm run build
npm run start
```

## 4. 배포

Vercel에 가장 간단하게 배포할 수 있습니다:
```bash
npx vercel
```
또는 Cloudflare Pages, Netlify 등 Next.js를 지원하는 어떤 플랫폼에도 배포 가능합니다.

## 5. 구현된 기능

- **사이드바**: 카테고리 트리(피드 그룹핑) + 카테고리별 미확인 기사 수 배지 + 피드 추가 버튼
- **피드 추가 모달**: 키워드 검색(구글 자동 변환) / 언론사 프리셋 원클릭 / 커스텀 RSS 직접 입력
- **필터 탭**: 전체 / 읽지 않음 / 읽음 / ★ 북마크 (각 탭 카운트 표시)
- **클러스터 카드**: 대표 키워드 태그, 다중소스 확인 스탬프, 유사 기사 아코디언(펼치기/접기)
- **읽음/북마크**: 기사 클릭 시 즉시 읽음 처리, 별 아이콘 클릭 시 북마크 토글 — 낙관적 업데이트(Optimistic UI) + 실패 시 자동 롤백

## 6. 설계상 참고 사항

- 초기 로드 시 전체 클러스터를 한 번에 가져와 클라이언트에서 카테고리/피드/필터를 계산합니다. 개인용 뉴스 리더 규모에서는 이 방식이 왕복 요청을 줄여 더 빠릅니다. 피드가 매우 많아지면(수백 개) 서버 사이드 페이지네이션으로 전환을 고려하세요.
- 카테고리/피드 필터는 각 클러스터의 **대표 기사(primaryArticle)** 기준으로 적용됩니다. 유사 기사가 다른 카테고리에 속한 경우에도 카드 자체는 대표 기사 기준으로 분류됩니다.
- 북마크 필터는 대표 기사든 유사 기사든, 클러스터 내 **하나라도 북마크되어 있으면** 카드 전체를 보여줍니다.
